# Dictionary App

A simple web app that looks up English words and shows their phonetic spelling, parts of speech, and definitions.

## Features

- Search any English word
- Shows phonetics and grouped definitions by part of speech
- Loading and error states (for example, "Word not found!")

## Tech stack

HTML · CSS · JavaScript (fetch / async-await) · Node.js · Express · [Free Dictionary API](https://dictionaryapi.dev/)

## Run locally

```bash
npm install
npm start
```

Then open http://localhost:3000.
